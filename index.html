Traffic-flow walkthrough STEP BY STEP

1 · Internet requestClient starts an HTTPS request to the public application entry point.
2 · Edge protectionDDoS protection and Azure Firewall apply the configured network controls.
3 · Hub to spokeRoutes and peering deliver approved traffic to the application spoke.
4 · WAF inspectionApplication Gateway WAF inspects HTTP(S) and forwards allowed requests.
5 · Application tierThe private workload processes the request using its managed identity.
6 · SQL Private LinkApp connects to Azure SQL using private DNS and a private endpoint.
7 · Storage Private LinkApp accesses the required Storage subresource over private connectivity.
8 · Key VaultApp retrieves authorized secrets or keys; access is audited and monitored.

Architecture reminder: Azure Firewall and Application Gateway are different controls. The WAF is the HTTP(S) Layer 7 entry point; private endpoints require correct private DNS resolution and service-side network settings. Azure Bastion is an administrative access path, not part of ordinary user traffic. The exact path depends on the chosen ingress design, route tables, firewall policy, and deployment model.
